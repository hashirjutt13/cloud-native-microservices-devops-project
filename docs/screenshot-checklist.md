# Screenshot Checklist

Capture these images for the final submission:

- GitHub repository home page showing public visibility.
- Branch list showing `develop`, `release`, and `main` or `production`.
- Pull requests from all three team members.
- GitHub Actions CI passing.
- Docker Hub repositories or image tags for all five images.
- Local `docker compose up --build` running successfully.
- Browser showing frontend dashboard at `http://localhost:8080`.
- Health endpoint responses for all four services.
- Jenkins successful pipeline stages.
- Kubernetes `kubectl get pods,svc,deploy -n cloud-final-development`.
- Kubernetes rollout status output.
- Render development, staging, and production URLs if used.
- Optional: canary/blue-green, HPA, or monitoring manifests applied.
